# O Nosso Casamento 💍

Site do casamento feito em HTML, CSS e JavaScript, publicado com GitHub Pages.

## Como editar a informação

Toda a informação (nomes, data, hora, locais, programa, dress code, lista de presentes, RSVP e FAQ) está no ficheiro **`config.js`**. Basta alterar os textos entre aspas e guardar.

Para editar diretamente no GitHub: abre `config.js` no repositório → clica no lápis ✏️ → altera → **Commit changes**. O site atualiza sozinho em 1–2 minutos.

## Ficheiros

- `index.html` – estrutura da página
- `style.css` – aspeto visual
- `script.js` – contagem decrescente, "adicionar ao calendário", menu, animações
- `config.js` – **a informação do casamento**
